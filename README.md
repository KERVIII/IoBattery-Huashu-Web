# IoBattery Huashu Web

A clean and lightweight WebUI for IoBattery, inspired by the Huashu design style.

## Features

- Battery information
- System information
- Huashu-inspired interface
- Mobile-friendly layout
- Easy to customize
- HTML, CSS, and JavaScript
